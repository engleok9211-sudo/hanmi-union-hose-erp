STEP 4. 외상매출금·원장거래처별 미수금 확인 및 전체 잔액 인쇄

① 견적서 입력 · 출력 견적서를 작성하고 거래명세서로 전환하기

  1. 견적 거래처 선택: 거래처를 선택합니다. (없는 거래처는 우측 상단 [+ 거래처 추가] 버튼으로 즉시 등록)
  2. 품목 입력: ⚡ 등록품목 빠른선택에서 고르거나 직접 품목명·규격·수량·단가를 입력합니다.
  3. 견적서 인쇄: 우측 미리보기 화면에서 [🖨️ 바로 인쇄 (A4)] 버튼을 누르면 정식 견적서가 출력됩니다.
  4. 거래명세서로 전환: [➡️ 견적 저장 후 거래명세서로 바로 전환] 버튼(또는 하단 목록의 [➡️ 거래명세서 발급])을 누르면 동일한 내용으로 거래명세서가 자동 생성되고 거래처원장에 즉시 반영됩니다.

② 거래명세서 입력 · 출력 명세서 발급 및 세금계산서 발행 체크

  1. 거래명세서 직접 작성: 견적서 없이 바로 명세서를 작성할 때도 거래처와 품목을 선택한 뒤 [💾 거래명세서 저장]을 누르면 즉시 저장 및 거래처원장에 반영됩니다.
  2. A4 거래명세서 출력: 우측에 공급자 보관용 + 공급받는자 보관용 (A4 2매 양식)이 자동 생성되며 [🖨️ 바로 인쇄 (A4)]로 출력합니다.
  3. 세금계산서 발행여부 체크: 별도의 복잡한 발행 화면 없이, 입력 폼이나 하단 명세서 목록(또는 거래처원장)에서 [✓ 발행완료] 체크박스만 클릭하면 즉시 발행 여부가 기록됩니다.

③ 입금 등록 & ④ 거래처원장 · 외상매출금 관리

  1. 입금 등록: 거래처를 선택하면 현재 받을 외상매출금 잔액이 크게 표시됩니다. [전액 입금] 또는 입금액을 입력하고 [💾 입금 내역 저장]을 누르면 미수금이 즉시 차감됩니다.
  2. 거래처별 상세 원장 확인: ④ 거래처원장 · 외상매출금 관리 좌측 표에서 거래처를 클릭하면 우측에 해당 거래처의 일자별 매출·입금·잔액 내역이 나타나며, 방금 입력한 거래처는 [방금입력] 배지와 함께 최상단에 고정됩니다.
  3. 외상매출금 전체 거래처 잔액 인쇄: 좌측 상단 [🖨️ 외상매출금 전체 잔액 인쇄] 버튼을 누르면 전체 거래처의 미수금 집계표가 A4 양식으로 인쇄됩니다. ([미수금만] 체크 시 미수금이 남아 있는 거래처만 인쇄)
4. 🟠 매입 관리 따라하기 (입고 등록 ➔ 상환 등록 ➔ 외상매입금 관리)
STEP 1. 매입(입고) 등록매입처 자재 입고 등록 및 세금계산서 수취 체크
STEP 2. 상환 등록 (출금)매입처 계좌 확인 및 외상대금 송금(출금) 기록
STEP 3. 외상매입금·원장매입처별 미지급 잔액 확인 및 전체 잔액 인쇄

① 매입(입고) 등록 ➔ ② 상환 등록 ➔ ③ 외상매입금 관리

  1. 매입(입고) 등록: 매입처(유로텍, 마누리코리아, 광일유압카프링 등)를 선택하고 입고된 호스·금구·부품 내역을 입력한 뒤 [💾 매입(입고) 저장]을 누릅니다. 세금계산서를 받았는지 여부도 체크박스로 간단히 체크합니다.
  2. 외상매입금 상환(출금) 등록: 매입처를 선택하면 현재 줄 외상매입금 잔액과 입금할 은행 계좌번호가 자동 표시됩니다. 송금 후 [전액 상환] 또는 상환금액을 입력해 저장합니다.
  3. 외상매입금 전체 거래처 잔액 인쇄: ③ 외상매입금 관리 좌측 상단의 [🖨️ 외상매입금 전체 잔액 인쇄] 버튼을 클릭하면 모든 매입처의 기초이월·당기입고·당기상환·미지급잔액 및 계좌번호가 A4 보고서로 출력됩니다.
5. ⚙️ 기초 등록 및 실무 꿀팁

기초 등록 거래처 및 품목·단가 추가 방법 (2가지 방법 모두 지원)

  • 방법 1 (작업 중 즉시 추가): 견적서·거래명세서·매입입고 화면 우측 상단의 [+ 거래처 추가], [+ 품목·단가 추가] 버튼을 누르면 작성하던 화면을 벗어나지 않고 팝업창에서 바로 추가할 수 있습니다.
  • 방법 2 (기초 등록 메뉴에서 일괄 관리): 상단 ⚙️ 기초 등록 탭에서 전체 매출거래처·매입거래처와 품목별 단가를 검색·수정·삭제할 수 있습니다.
💡 자동 품목 등록 기능: 견적서나 거래명세서 작성 시 목록에 없는 새로운 품목명과 단가를 직접 입력하여 저장하면, 다음번부터 선택할 수 있도록 해당 거래처의 품목 마스터에 자동으로 추가 등록됩니다.
